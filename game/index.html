            How to play

            1. Set up a model

            Open Settings. The table has three rows: text, vision, and image.

            The text row is the only row that the game uses now. Its model plays the interviewer and writes the grade. Select a provider, then type the model name. Add your API key only when the endpoint needs one; an empty key calls without it. Select Test connection to check the row.

            The vision row will read your handwritten notes from a photo. The image row will draw the interviewer. A later release adds both, so you can leave the two rows empty.

            The mock provider needs no key and works offline. It gives scripted replies, so you can learn the controls at no cost.

            The game stores your keys in the local storage of this browser. Local storage is the data store of one site in one browser. The game sends a key only to the provider of its row.

            The thinking effort of a row tells its model how much to reason before it answers. The meanings of the first two entries do not depend on the provider. Default omits the reasoning field, so the provider picks. Providers disagree on that pick: some models answer with medium, others with high. Off asks for no reasoning at all. OpenAI-style endpoints receive the value none. Anthropic-style endpoints just leave thinking out, because thinking there is opt-in. The rest of the ladder passes through to OpenAI-style endpoints verbatim. A model that lacks a value rejects the request, so pick what your model supports. Anthropic-style endpoints receive a thinking budget instead: 1024, 2048, 8192, 16384, 32768, 65536, and 131072 tokens from minimal to ultra. The effort applies to the text and vision rows.

            2. Choose the options

            Help mode
            Learning: ask for a hint at any time. Each further request gives a fuller hint, up to a walkthrough. The step tracker lists the five process steps, and you can hide it. Testing: no hints. The interviewer refuses a request, and the step tracker is hidden. Use this mode to measure yourself.
            Constraints
            Unconstrained: choose any technology. Constrained: the interviewer pins a stack, and you design within it.
            Proactive guidance
            Learning mode only. Off is the default: the interviewer answers what you ask and then waits. On: the interviewer can end a reply with one pointer to an area that you did not visit.
            Prepared probes per step
            Learning mode only. The interviewer holds a few prepared questions for the current step. The select caps how many of them it may ask in one step: 0 keeps it fully reactive, 2 is the default.
            Timer
            Off, or 15, 30, 45, or 60 minutes. The clock runs only on your turn. It pauses while the interviewer responds, during a progress grade, and after a reload. When the time is over, the interview wraps up and is graded.

            3. During the interview

            Start with clarifying questions about scale and requirements. Type below the chat and press Enter.

            Type your whole turn in one box: plain prose, equations wrapped in $$dollars$$, and diagrams in ```mermaid fenced blocks, in any mix and order. Equations render as math and diagrams render as drawings in the chat. The game attaches each block to your current step, and the grader reads it.

            Round your numbers aggressively and show the reasoning. An answer within one order of magnitude passes. An order of magnitude is a factor of ten. False precision counts against you.

            Agree to end appears when all five steps have evidence. Select it to wrap up and get your grade.

            In learning mode, Request progress grade gives a progress report. It costs tokens. The clock pauses for the report.

            4. The grade and the errors

            The score is 0 to 10. Eight diagnostic rows make it: each row passes or fails, and a failed row comes with a fix. The feedback also lists the realism of your estimates, the items that you missed, comments on your submissions, and the closing of the interviewer. Steps count by coverage, not by order, so you can go back.

            If a call to the provider fails, the game shows the reason and a Retry button. The session is saved in this browser, so a reload continues the interview.

            Select Export transcript to download the interview as a Markdown file: the problem, the options, the full transcript with your submissions, and the grade.
